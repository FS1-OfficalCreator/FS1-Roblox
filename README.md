# 🔥 FS1 — Natural English & Emoji Coding for Roblox
**Created by FS1-coding creator**

> **"Trash at coding? Hate memorizing Luau symbols? FS1 lets you build anything in Roblox using plain, properly spelled English and emojis wrapped in `(: ... :)`."**

FS1 is a universal Roblox programming language with ZERO limits. Wrap any plain-English command—or even emojis—inside `(:` and `:)` and FS1 builds it.

## Official FS1 Rules
1. **Use FS1 Tags:** Every command MUST start with `(:` and end with `:)`.
2. **Spell Properly:** Typos or missing tags will fail to compile!
3. **Emojis Supported:** You can use emojis directly inside `(: ... :)` to design icons, themes, and powers!

## Signature Examples
*(Note: FS1 has ZERO limits—these are just examples. Literally ANY command inside `(: ... :)` works!)*

* **Emoji UI Styling:** `(:make the chat look like 💬:)` ✅
* **God Mode:** `(:infinite health:)` or `(:unlimited health:)` ✅
